# Survey Data Investigation

## Project Overview
This project analyzes survey data using Python, Pandas, SQL, and data visualization techniques. It explores employment patterns, annual compensation, countries, and remote work arrangements among survey respondents.

## Objectives
- Load and explore survey data using Python.
- Analyze annual compensation and employment patterns.
- Use SQL queries to summarize survey responses.
- Compare respondents across countries.
- Explore remote work arrangements.
- Create graphs to communicate findings.

## Tools and Technologies
- Python
- Pandas
- SQLite
- SQL
- Matplotlib
- CSV datasets

## Project Files
- `Survey_Project_New.py` — Main Python analysis script.
- `salary_distribution.png` — Annual compensation distribution graph.
- `country_respondents.png` — Top 10 countries by respondent count.
- `country_analysis.csv` — Country-wise analysis results.
- `remote_work_analysis.csv` — Remote work analysis results.
- `employment_analysis.csv` — Employment analysis results.

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas matplotlib`
3. Place the survey dataset in the project folder.
4. Run:
   `python Survey_Project_New.py`

## Dataset
The project uses the Stack Overflow Developer Survey 2023 dataset. The original dataset must be downloaded separately and placed in the project folder before running the script.

## Conclusion
This project demonstrates how Python, SQL, and visualization tools can be used to explore survey data and summarize patterns in employment, compensation, country distribution, and remote work.
